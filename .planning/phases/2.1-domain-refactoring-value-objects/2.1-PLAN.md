# Phase 2.1: Domain Refactoring (Value Objects & DTOs) - Plan

## Wave 1: Core Value Objects (Primitive Obsession)

### Task 1.1: Input Value Objects
- **Action:** Criar em `objects/`: `topic.py`, `knowledge_level.py`, `focus_time.py`, `study_days.py`.
- **Logic:** Mover as validações de `models/prompt.py` e `models/guide.py` para o `__post_init__` desses objetos (dataclasses frozen).
- **Acceptance Criteria:** Testes unitários para cada VO garantindo que não é possível instanciar um objeto inválido.

### Task 1.2: Identity Value Objects
- **Action:** Criar em `objects/`: `username.py`, `user_id.py`, `guide_id.py`.
- **Acceptance Criteria:** Tipagem forte para IDs em toda a aplicação.

## Wave 2: DTOs & Session Refactor

### Task 2.1: Firebase User DTO
- **Action:** Criar `dtos/firebase_user.py` para encapsular o dicionário retornado pelo Firebase Admin Auth.
- **Read First:** `models/session.py`.
- **Acceptance Criteria:** Substituição de `user: dict` por `FirebaseUserDTO` em `models/session.py`.

### Task 2.2: Refactor `models/session.py`
- **Action:** Atualizar `create` e `verify_cookie` para usar o novo DTO.
- **Acceptance Criteria:** Suite de testes de sessão (Phase 2) continua passando 100%.

## Wave 3: Prompt & Guide Refactor

### Task 3.1: Prompt Value Object/DTO
- **Action:** Criar `objects/prompt.py` ou refatorar `models/prompt.py` para uma classe `Prompt`.
- **Composition:** `Prompt` deve conter `Topic`, `KnowledgeLevel`, `FocusTime` e `StudyDays`.
- **Methods:** Adicionar `to_xml()` à classe `Prompt`.
- **Acceptance Criteria:** Validação de relevância (IA) integrada como método de classe ou serviço.

### Task 3.2: Guide Refactor
- **Action:** Refatorar `models/guide.py` para usar os novos VOs e DTOs.
- **Acceptance Criteria:** Remoção de acessos por chave de dicionário (`user_input["topic"]`) em favor de atributos de objeto.

## Wave 4: Final Integration & Cleanup

### Task 4.1: End-to-End Verification
- **Action:** Rodar todos os testes unitários e de integração.
- **Acceptance Criteria:** 100% pass.
